# Планета Земля — викторина по географии

Игра для детей: на экране трёхмерный глобус с преувеличенным рельефом — горы и нагорья видны как настоящие возвышения. Его можно крутить и приближать. Игра задаёт вопрос («Найди Африку», «Найди самые высокие горы»), а ребёнок находит ответ на глобусе и тыкает в него. За правильные ответы игра даёт звёзды, а за пройденный уровень показывает салют.

## Запуск

Нужен [uv](https://docs.astral.sh/uv/) и Python 3.13.

```bash
uv run main.py
```

Окно открывается развёрнутым на весь экран. При первом запуске игра спросит имя игрока. Игроков может быть несколько — сменить игрока можно в меню уровней. Прогресс (звёзды и открытые уровни) у каждого игрока свой и сохраняется в `progress.json` рядом с игрой. Чтобы начать всё заново, удалите этот файл. Прогресс прежних версий игры (с семью уровнями) не переносится — после обновления все начинают с чистого листа.

## Управление

- **Крутить глобус** — зажать кнопку мыши и тянуть.
- **Ответить** — коротко нажать на нужное место глобуса.
- **Приблизить или отдалить** — колесо мыши, прокрутка на тачпаде, кнопки «+» и «−» или клавиши `+` и `-`.
- **«Дальше»** — кнопка, `Enter` или пробел.
- **Выйти в меню** — `Esc` или кнопка «В меню».

## Уровни

1. Материки
2. Океаны (4 океана)
3. Полюса и экватор
4. Острова и полуострова
5. Моря, заливы и озёра
6. Горы, равнины и пустыни
7. Вершины и вулканы
8. Загадки

В начале открыт только первый уровень. Следующий открывается, когда на предыдущем набрано не меньше 2/3 возможных звёзд; на экране итога сразу есть кнопка «Следующий уровень». На каждый вопрос даётся 3 попытки. После промаха игра говорит, куда попал ребёнок, и подсказывает, в какую сторону искать.

## Для разработчика

```bash
uv run pytest
```

```bash
uv run main.py --debug-regions
```

```bash
uv run python -m tools.region_map map.png --regions
```

```bash
uv run python -m tools.bench_render
```

```bash
uv run python -m tools.convert_stl
```

- `pytest` — тесты.
- `--debug-regions` — глобус раскрашен по материкам и океанам, а при клике выводятся координаты и регионы.
- `tools.region_map` — плоская карта модели с сеткой. Помогает править `globe_quiz/data/regions.json`.
- `tools.bench_render` — замер скорости отрисовки.
- `tools.convert_stl` — заново строит облегчённую модель `assets/earth_relief.npz` из `assets/World-Full-Final.STL` (упрощение схлопыванием рёбер, ~20 секунд). Игра читает только `.npz`.

Вопросы хранятся в `globe_quiz/data/levels.json`, контуры объектов — в `globe_quiz/data/regions.json` (горы и равнины задаются контуром и высотой, вершины — точкой). Раскраска модели — в `globe_quiz/model.py` (полосы высот) и `globe_quiz/data/coloring.json` (пустыни, Гренландия), сведения об авторе модели — в `globe_quiz/data/model.json`.

## Модель Земли

3D-модель «[The Whole World](https://www.thingiverse.com/thing:671647)», автор [Davision3d](https://www.thingiverse.com/Davision3d/designs), лицензия [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) (только некоммерческое использование). Автор и лицензия указаны и на заставке игры.

Изменения в игре: модель упрощена с 231 тысячи до 12 тысяч треугольников, срезанный под подставку юг закрыт ледяным куполом, а суша раскрашена по высоте (в исходной модели цветов нет). Высоты не менялись — в модели они нарочно преувеличены.
