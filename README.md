# Планета Земля — викторина по географии

Игра для детей: на экране трёхмерный глобус, который можно крутить и приближать. Игра задаёт вопрос («Найди Африку», «Найди самые высокие горы»), а ребёнок находит ответ на глобусе и тыкает в него. За правильные ответы игра даёт звёзды, а за пройденный уровень показывает салют.

## Запуск

Нужен [uv](https://docs.astral.sh/uv/) и Python 3.13.

```bash
uv run main.py
```

Окно открывается развёрнутым на весь экран. При первом запуске игра спросит имя игрока. Игроков может быть несколько — сменить игрока можно в меню уровней. Прогресс (звёзды и открытые уровни) у каждого игрока свой и сохраняется в `progress.json` рядом с игрой. Чтобы начать всё заново, удалите этот файл.

## Управление

- **Крутить глобус** — зажать кнопку мыши и тянуть.
- **Ответить** — коротко нажать на нужное место глобуса.
- **Приблизить или отдалить** — колесо мыши, прокрутка на тачпаде, кнопки «+» и «−» или клавиши `+` и `-`.
- **«Дальше»** — кнопка, `Enter` или пробел.
- **Выйти в меню** — `Esc` или кнопка «В меню».

## Уровни

1. Материки
2. Океаны (4 океана)
3. Полюса и экватор
4. Острова и полуострова
5. Моря и заливы
6. Горы и пустыни
7. Загадки

В начале открыт только первый уровень. Следующий открывается, когда на предыдущем набрано не меньше 2/3 возможных звёзд; на экране итога сразу есть кнопка «Следующий уровень». На каждый вопрос даётся 3 попытки. После промаха игра говорит, куда попал ребёнок, и подсказывает, в какую сторону искать.

## Для разработчика

```bash
uv run pytest
```

```bash
uv run main.py --debug-regions
```

```bash
uv run python -m tools.region_map map.png --regions
```

```bash
uv run python -m tools.bench_render
```

- `pytest` — тесты.
- `--debug-regions` — глобус раскрашен по материкам и океанам, а при клике выводятся координаты и регионы.
- `tools.region_map` — плоская карта модели с сеткой. Помогает править `globe_quiz/data/regions.json`.
- `tools.bench_render` — замер скорости отрисовки.

Вопросы хранятся в `globe_quiz/data/levels.json`, контуры объектов — в `globe_quiz/data/regions.json`. Контуры островов, которых нет в модели, лежат в `globe_quiz/data/islands.json`: острова строятся при загрузке (`globe_quiz/islands.py`), а файлы в `assets/` не меняются.

## Модель Земли

3D-модель «[Low Poly Planet Earth](https://sketchfab.com/3d-models/low-poly-planet-earth-7b1dc4f802a54a6297e7a46888a85f77)», автор [Jacobs Development](https://sketchfab.com/Jacobs_Development), лицензия [CC-BY-4.0](http://creativecommons.org/licenses/by/4.0/). Автор и лицензия указаны и на заставке игры. В игре модель дополнена: дорисованы Японские острова, Мадагаскар и Исландия.

Модель низкополигональная, поэтому некоторых мест в ней нет: Японии, Исландии, Мадагаскара. Такие места в викторину не включены.
